## Como manter este inventário

1. Atualize as dependências de forma deliberada e regenere `frontend/package-lock.json` usando `npm ci`/`npm install` na versão de Node documentada.
2. Gere a lista do frontend novamente a partir do campo `packages[*].license` do lockfile; investigue qualquer licença ausente ou incompatível antes de integrar.
3. Compare as versões Python do build candidato com `backend/requirements.txt` e leia `License-Expression`, `License-File` e os classifiers dos metadados instalados.
4. Atualize este documento, preserve os arquivos de licença das distribuições e confirme que os avisos requeridos continuam acessíveis na interface.
5. A licença do Nivus é AGPL-3.0-only; a licença do projeto não substitui os termos das dependências. Este inventário não é uma análise jurídica de compatibilidade.
